# Public assets

- `public/video.mov` — scroll-driven hero video (already in place). Frames advance with scroll position.
- `public/18635541.jpeg` — profile photo (already in place, used in About).
- `public/music.mp3` — **drop your audio file here** to enable background music.

The site probes `/music.mp3` on load. If the file isn't present, the SOUND toggle in the bottom-right is hidden automatically. If you add a file later, just refresh.

Recommended audio: ambient/instrumental loop, ~30–60s, MP3 ~128–160 kbps, < 2 MB.
